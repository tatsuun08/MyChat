# MyChat
セキュアで高速なチャットを実装しながら，モダンなアーキテクチャについて学習する

## 概要
### 使用技術
フロントエンド：
* Kotlin
* Android SDK

ライブラリ
* Retrofit API通信
* Gson JSON変換
* Room ローカルDB処理
* Croutines 非同期処理
* Navigation Component

バックエンド：
* Go言語

ライブラリ
* net/http
* GORM

データベース
* PostgreSQL（サーバー）
* SQLite（ローカル）
